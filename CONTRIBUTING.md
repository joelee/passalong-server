# Contributing to passalong-server

passalong-server is proprietary for now (see [LICENSE](LICENSE)) and does
not accept outside contributions until an open-source licence is chosen.

Bug reports and ideas are welcome as issues. Report security problems
privately, as [SECURITY.md](SECURITY.md) explains.

The passalong client is open source and does accept contributions:
<https://github.com/joelee/passalong>.

## For maintainers and agents

[AGENTS.md](AGENTS.md) holds the rules: test first, `just check` before
every push, line coverage of at least 80 %, documentation and
[CHANGELOG.md](CHANGELOG.md) updated with the change. Nothing from this
repository may be copied into the Apache-2.0 client.
