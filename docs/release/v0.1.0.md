## Summary

passalong-server is a self-hosted HTTPS server for
[passalong](https://github.com/joelee/passalong), the clipboard and file
sharing tool: an alternative to keeping a passalong store on an SSH server
or in a local folder.

- **One server, many workspaces**, each a separate passalong store, reached
  with API keys that expire, can be revoked, and are stored only as hashes.
- **Zero knowledge of encrypted workspaces.** The server stores sealed items
  and never sees a key, the words, or plaintext. Migrating a workspace to
  encryption and rotating its key are sessions a second device can finish
  or undo when the first one dies.
- **REST + JSON**, [documented](https://github.com/joelee/passalong-server/blob/main/docs/api/README.md)
  and tested against the code, with content as HTTP streams: nothing is held
  whole in memory, whatever its size.
- **TLS built in**, with a certificate of your own, from Let's Encrypt
  (`tls letsencrypt` prints how), or self-signed and pinned; or plain HTTP
  behind your reverse proxy. No switch turns certificate checking off.
- **Docker or systemd**, each one command, each tested end to end.
- **Free software**, under the GNU AGPL, version 3 or later.

**No passalong client speaks to it yet.** The client learns the protocol in
its v0.3.0. Until then the server can be run, administered, and looked at
with `curl`; see
[usage](https://github.com/joelee/passalong-server/blob/main/docs/usage.md#a-session-with-curl).

## Install

**Docker**, amd64 and arm64:

```text
docker pull joeworks/passalong-server:0.1.0
```

and the [Compose walkthrough](https://github.com/joelee/passalong-server/blob/main/deploy/docker/README.md).

**systemd**: the archive for your architecture, below, checked against
`SHA256SUMS`; then `sudo ./passalong-server service install --host <name>`.
The binaries need glibc 2.35 or later (Debian 12, Ubuntu 22.04, and newer).
See [usage](https://github.com/joelee/passalong-server/blob/main/docs/usage.md#installing).

## Compatibility

| passalong-server | API | passalong client |
|---|---|---|
| 0.1.x | v1 | 0.3.0 and later (planned) |

Linux only. The control database is at schema version 3.
